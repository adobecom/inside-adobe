# welcome

Homepage greeting: today's date (filled in when the page loads), a heading and a button.

## Authoring (Document Authoring)

Model: `standalone`

One row, two cells: the heading (for example `Welcome`) | a **bold** link, which renders as the
blue button (for example **More News**).

# events

Upcoming events list with a heading and a **More Events** button. The list is authored, so keep
it current by hand.

## Authoring (Document Authoring)

Model: `standalone`

- Row 1: the heading (`Events`) | a **bold** link to the calendar (renders as a button).
- One row per event: date as `OCT 12` | location | event title, linked to the event page.

## Supported variations

No variations.

# card-resource

Custom **card** block. Place several in one section with section metadata `grid` (2 or 3) and
`style` `container`.

## Authoring (Document Authoring)

Model: `standalone`

One row, one cell: an H3 title and an image, in either order (the block keeps the authored order),
then optional paragraphs and a bulleted link list. Link the image to make it clickable.

## Supported variations

- `card-resource (video)` — draws a play button over the image. Link the image to the video.

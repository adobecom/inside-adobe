# related-cards

Photo tiles linking to related pages: image, title and short description, with a dark gradient.
Four per row on wide screens, two on tablets, one on phones.

## Authoring (Document Authoring)

Model: `standalone`

One row per card, two cells: the image | the title as a linked Heading 3, then the description.
The whole tile links to the title's link.

On landing pages (page metadata `Template` = `full-width`) the cards usually sit in a gray band:
section metadata `style` = `band` (60px padding, larger section heading).

## Supported variations

No variations.

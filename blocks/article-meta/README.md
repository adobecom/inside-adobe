# article-meta

News article tags and publish date, shown above the headline.

## Authoring (Document Authoring)

Model: `standalone`

- Row 1: the collection tag link (pink) | one or more topic tag links (outlined).
- Row 2: the date as it should read, for example `September 30, 2026`.

Also set page metadata `Publication Date` (`YYYY-MM-DD`); the homepage news grid sorts on it.

Use it on pages with page metadata `Template` set to `article`, which loads
`templates/article/article.css` (narrower article column, right-aligned **More News** button,
normal-weight body links).

## Supported variations

No variations.

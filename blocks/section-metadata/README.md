# section-metadata

Section settings (Author Kit). Besides `grid`, `gap`, `spacing`, `container`, `background` and
`layout`, this project adds one section style:

- `style: collapsible`: the section's first heading becomes a clickable title and everything
  after it collapses below (closed by default; opened when the URL's #hash points inside it).
  Put anything in the section, including tables, cards and accordions. Consecutive collapsible
  sections stack with a divider between them.

# accordion

Expandable questions and answers, with an Expand All / Collapse All link.

## Authoring (Document Authoring)

Model: `standalone`

One row per item, two cells: question | answer. Put a heading (for example an H3) right above
the block; the Expand All link lines up with it.

## Supported variations

No variations.
